# 交互约定

本文维护五个计算模块的行为规则；视觉规范见 [DESIGN.md](../DESIGN.md)，执行命令见 [验证手册](验证手册.md)。本轮只修正表现层，不改变算法、存储协议或求解策略。

## 流程

通用规则适用于五个模块，合理差异见后表。普通输入不抢焦点、不滚动、不自动求解；重复输入不重建相同提示。

| 触发动作 | 界面状态 | 反馈文案 | 数据影响 | 焦点 / 滚动行为 |
|---|---|---|---|---|
| 首次进入、空白输入 | 显示搭题入口 | 从一道题开始；空白按 0 | 不预置题目 | 自然顺序 |
| 输入、修改 | 原文保留；旧结果立即失效 | 输入已修改，请重新求解 | 更新当前模块草稿 | 不移动 |
| 增减变量、约束、行列 | 保留仍存在的输入，更新按钮 | 有旧结果时提示重新求解 | 同上，上限不变 | 删除约束转相邻入口；焦点节点移除或禁用时退回本组可用入口 |
| 切换方向、变量类型 | 选中态与 aria-pressed 一致 | 有旧结果时提示重新求解 | 更新当前草稿 | 保持当前控件 |
| 载入示例 | 替换输入，旧结果失效 | 保留失效或草稿反馈 | 更新草稿，历史保留 | 保持示例按钮 |
| 求解成功 | 展示 core 结论和快照 | 最优仅用于已确认状态 | 按既有规则记录历史 | 单纯形滚到结果；其他模块保留位置 |
| 校验失败 | 汇总错误和已有字段标记 | 显示校验信息 | 不记录错误题为成功历史 | 定位首个已标记错误；无法可靠定位时仅汇总，不解析中文猜字段 |
| 不可行、无界、达到限制、无法确认 | 分别显示状态和可用过程 | 无可行解 / 无界 / 未收敛或未确认最优 | 记录规则不变 | 无假进度或人为等待 |
| 编辑结果对应输入 | 灰显或清除结果 | 保留结果写明“修改前的题目”；清除后提示重新求解 | 草稿更新，历史快照不变 | 不移动，停止依赖旧题的分析 |
| 恢复历史 | 只恢复输入，清理结果 | 已恢复，请重新求解；保存失败另行说明 | 写当前草稿，不自动求解 | 历史折叠，焦点回标题 |
| 删除单条、清空历史 | 更新列表与数量，清空保留确认 | 已删除 / 已清空；失败提示重试 | 仅当前模块历史，保留题目和草稿 | 回历史标题 |
| 清空当前题目 | 清空本模块输入与结果 | 已清空；删除草稿失败提示刷新可能恢复旧题 | 仅当前草稿，不动历史及其他模块 | 留在清空按钮 |
| 刷新、草稿恢复 | 校验后恢复原文，不恢复结果 | 已恢复，请重新求解 | 键名、版本、结构不变 | 初始自然顺序 |
| 存储不可用、损坏 | 仍可输入求解，忽略坏数据 | 无法保存 / 无法读取，不显示虚假成功 | 不使用 localStorage.clear()；历史 20 条和去重规则不变 | 不强制确认或跳转 |
| 路由切换 | 显示目标页，保留输入与阅读状态 | 底栏选中与页面一致 | 不清空或求解 | 回顶部；隐藏页焦点转目标标题，底栏露出 |
| 完整、单步、运输播放 | 同一快照，保留步骤位置，首尾按钮禁用 | 步数、帧数及播放状态 | 不重新计算，不写草稿 | 恢复既有折叠状态；切页或隐藏暂停，编辑或重算销毁运输播放器；减少动态效果保留手动操作 |

## 合理差异

| 模块 | 保留行为及依据 |
|---|---|
| 单纯形 | 灰显旧结果供对照，明确属于修改前题目，并隐藏扩展分析；保持文字可读。零维模型仍交 core 判断。 |
| 灵敏度 | 修改基准题清除基准解、分析与旧场景；恢复场景等待基准重算后还原。修改场景只使分析失效。分析依赖已确认的基准最优解。 |
| 整数规划 | 编辑即清除结果；方法适用性和限额由 core 决定。未完成分枝的当前解在方法和图解中均写未确认最优；无候选解也不能据此判不可行。 |
| 指派 | 编辑即清除结果；空矩阵有 core 定义的空问题结论，禁止标记使用既有解析规则。 |
| 运输 | 编辑即清除结果并销毁计时器、观察器及事件；供需预览继续调用 core。空题须补产地、销地；虚拟线路和禁运规则不变。 |

## 本轮差异处置

- 统一失效提示持续性、幂等反馈、可靠错误定位、删除及切页焦点、分段控件选中语义。
- 修正整数分枝、图解和灵敏度场景对未完成状态的过度结论；主题保存失败时说明本次生效，并保留本次选择响应系统变化。
- 保留灰显与清除、空题校验、基准与场景生命周期、历史确认等业务差异。
- 视觉文档校正五模块描述；仅整理本轮涉及的重复状态样式，不做全面 CSS 重构。
