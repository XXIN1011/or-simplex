# 环境要求与常见问题

本文提供可复用的环境要求和排查方法。命令在仓库根目录执行，不依赖维护者的个人设备或目录配置。

## 1. 环境要求

| 工具 | 用途与要求 |
|---|---|
| Node.js | 运行构建、库、命令行和测试；支持范围见 `package.json` 的 `engines` |
| Git | 版本控制和发布；认证由当前环境的受支持工具管理 |
| Chrome / Chromium / Edge | 无头浏览器回归、截图和无障碍审查 |
| Python 与 NumPy / SciPy | 算法独立对拍；CI 使用的版本见工作流配置 |
| Bash | 执行 `tools/verify-visual.sh` 等脚本 |

网页运行时不依赖这些开发工具，可直接打开构建后的 `index.html`。

`lib/chrome.js` 先读取 `CHROME`、`CHROME_PATH` 或 `CHROME_BIN` 环境变量，再查找受支持平台的常见浏览器位置。自动检测失败时，在当前环境中指定浏览器可执行文件，不把个人安装目录写入仓库。

跨平台调用注意 shell 的引号、路径和通配符规则。优先使用仓库相对路径及项目提供的 npm 命令，避免把某一环境的 shell 行为当作通用约定。

## 2. 常见问题

| 问题 | 现象 | 排查方法 |
|---|---|---|
| 远程连接或认证失败 | Git 无法读取或推送远程分支 | 区分网络、认证和权限问题，检查当前环境配置；不要输出认证材料 |
| 题库文件不存在 | `crosscheck-*.py` 找不到输入文件 | 先运行对应的 Node.js 题库生成脚本，顺序见 [验证手册](验证手册.md) |
| Pages 版本未更新 | 部署前或缓存刷新前仍返回旧页面 | 查看 Pages 部署状态，再使用禁止缓存的请求核对内容 |
| Node.js 测试统计格式差异 | 测试通过但汇总脚本未解析到统计 | `test/run-all.js` 同时识别 TAP 和 spec 汇总；升级运行环境后检查实际输出 |
| 直接向测试命令传目录 | 某些 Node.js 版本报告 `MODULE_NOT_FOUND` | 使用 `npm run test:unit`，由编排脚本列出测试文件 |
| 历史模块残留检查命中 | `tools/check-no-dp.js` 返回非零状态 | 按报告定位残留；不要通过改名、删除断言或放宽模式隐藏问题 |
| 行尾转换提示 | Git 提示 LF 与 CRLF 转换 | 检查是否仅为行尾规范化；比较生成文本时统一行尾 |
| CI 浏览器启动超时 | UI 回归前提示调试端口未就绪 | 读取 Actions 诊断及附件；启动工具有总时限、单次探测超时和进程退出检查，不应跳过回归 |
| 动画断言未生效 | 测试量到的过渡为 `none` | 核对 `prefers-reduced-motion`；测试动画时显式模拟 `no-preference`，结束后恢复 |
| 显示模式测试不一致 | 模拟系统偏好与显式主题混用 | 使用 `setEmulatedMedia` 模拟系统偏好，分别验证跟随系统与显式选择 |
| 远程审查时尺寸异常 | 页面未完成渲染就量测控件 | 确认目标模块可见并等待页面稳定，避免直接放宽尺寸阈值 |
| 旧 WebView 缺少集合方法 | `querySelectorAll(...).forEach` 不可用 | 产品代码使用 `Array.prototype.forEach.call(...)` |
| 注释意外结束 | 注释中的终止符造成语法错误 | 检查块注释内是否出现提前闭合的符号 |
| 搜索命中构建副本 | `index.html` 与源码出现重复结果 | `.ignore` 默认排除构建产物、预览目录和生成题库；需要检查产物时显式指定文件 |
| 构建后改动消失 | 直接编辑的 `index.html` 被覆盖 | 修改 `src/` 中的源文件，再运行 `npm run build` |

## 3. 调试流程

1. 用尽可能小的输入复现问题，记录预期结果、实际结果和必要的运行条件。
2. 算法问题先调用核心 API 检查；界面问题再使用浏览器回归或 CDP 读取页面状态。
3. 涉及迭代过程时，对照计算快照和相关算法回归，避免只比较最终目标值。
4. 对独立求解器的分歧进行数学复核，必要时更换预处理设置或参考实现。
5. 修复后补充能覆盖根因的回归。只有确认测试本身有误时才调整测试，并说明原因。
6. 分享诊断前移除真实输入中的个人信息、认证材料和个人环境细节；日志只保留定位所需内容。

常用验证命令和失败判据见 [验证手册](验证手册.md)，远程认证与发布流程见 [推送与部署](推送与部署.md)。
