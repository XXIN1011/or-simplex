# 单纯形法计算器（Simplex Calculator）

一个面向**教学**的线性规划求解器。与常见的"只给答案"的求解器不同，它把单纯形法的**每一步迭代完整摊开**给学生看。

手机优先设计，单文件、零依赖、可离线。

## 功能

- 支持 `max` / `min` 以及 `≤` / `≥` / `=` 任意组合的约束
- 自动识别并处理三类边界情况：**无可行解**、**无界解**、**多重最优解**
- 负数右端项自动整行取负并翻转关系符（保证初始基可行）
- `min` 问题自动按 `max` 求解后还原目标值

### 教学特性

| 特性 | 说明 |
|---|---|
| 完整单纯形表 | 每一轮迭代的系数矩阵，含松弛变量 `s`、人工变量 `a` |
| 符号化大 M | 检验数按教材写法显示为 `7M - 4` 这类形式，而非近似大数 |
| 三重高亮 | 入基列（蓝）、出基行（橙）、枢轴元素（黄底橙边） |
| 自动讲解 | 每张表下自动生成 `① 选入基 → ② 比值检验（列出每个 θ 的计算）→ ③ 枢轴变换` |
| 标准化 | 求解前先展示「原问题 → 标准型」的完整变换：min 转 max、加减松弛/剩余变量、引入人工变量 |
| 图解法 | 2 变量时自动画出可行域、目标函数等值线与最优顶点（内联 SVG） |
| 对偶解 | 由最终基算出影子价格 `y = c_B·B⁻¹`，并标出哪些约束还有余量 |
| 退化提示 | 最小比值 θ = 0 时明确指出这一步不会改善目标值 |
| 符号说明 | 可折叠地解释 x/s/a、σ、M、基变量、z 的含义 |
| 深色模式 | 跟随系统 `prefers-color-scheme` 自动切换 |
| 溢出提示 | 表格超宽时提示可左右滑动 |

## 使用

直接用浏览器打开 `index.html`，或访问线上版本。

在手机上：浏览器打开 → 菜单「添加至桌面」，即可获得图标、全屏、离线可用的 App 体验。

## 代码结构

```
index.html          成品（单文件，构建产物）
simplex-core.js     算法核心：大 M 法单纯形法 + 对偶解 + 退化标记
graph.js            图解法：可行域 / 等值线 / 最优点的 SVG 绘制
ui.js               界面逻辑：输入表 ↔ 状态 ↔ 渲染
template.html       HTML 骨架 + CSS（含深色模式变量）
build.js            构建：把上面几者打包成 index.html
edge-test.js        验证：0 变量 / 0 约束等边界情形
dual-test.js        验证：对偶解经典例题 + 生成题库
crosscheck.py       验证：2000 道随机题对拍 scipy/HiGHS
crosscheck-dual.py  验证：对偶解的强对偶 + 互补松弛 + 中心差分扰动
verify-ui.js        验证：无头浏览器下的 UI 回归（17 项）
shot.js             工具：手机视口截图（可模拟深色模式）
```

源码中算法只有**一份**（`simplex-core.js`），构建时内联进 `index.html`，因此不存在两份实现失同步的问题。

## 构建与验证

```bash
node build.js                  # 重新生成 index.html
node test-simplex.js           # 经典例题 + 生成随机题库
python crosscheck.py           # 2000 道随机题对拍 scipy（需 numpy/scipy）
node verify-ui.js              # 无头浏览器 UI 回归（需 Chrome）
```

## 关于正确性

线性规划求解器的错误往往很隐蔽——绝大多数题都能算出"看起来对"的答案。因此本项目用两道独立关卡验证：

1. **算法层**：2000 道随机题（刻意混入高比例 `≥`/`=` 约束与负右端项）与 scipy 的 HiGHS 求解器对拍，**目标值、问题状态、解向量可行性三层全部一致**。
2. **界面层**：Chrome 无头浏览器在真实手机视口下跑 6 项回归（5 个例题 + 6 变量/8 约束极限尺寸），验证渲染正确且无 JS 报错。

开发过程中该对拍确实揪出过一个理论性缺陷：大 M 法在"含人工变量的扩展问题"上迭代，当入基列无正系数时不能一律判无界——若此时人工变量仍留基取正值，正确结论是**无可行解**。

## 算法说明

采用**大 M 法**。人工变量在目标函数中罚 `-M`，`M` 以符号形式（系数对 `(常数, M 系数)`）参与运算，比较时按 `M → +∞` 的字典序进行。这样既能得到教材级的标准显示，又避免了用 `1e9` 之类大数近似带来的数值精度问题。
