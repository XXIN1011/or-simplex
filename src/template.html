单纯形法

线性规划 · 大 M 法 · 逐步迭代

符号说明
  • x1, x2 …决策变量，就是你要决定的量。
  • s1, s2 …松弛 / 剩余变量。≤ 约束里加进去，表示「还剩多少没用完」；≥ 约束里减掉，表示「比要求多出多少」。作用是先把不等式变成等式，才能套用单纯形法。
  • a1, a2 …人工变量。约束里出现 ≥ 或 = 时凑不出初始单位基，于是人为添一个变量顶上。最优解中它必须退到 0，否则说明原问题无可行解。
  • M形式上「无穷大」的正数。人工变量在目标函数里带 −M 的代价，逼它退到 0。表格以符号形式显示为 3M − 4 这类形式。
  • σ检验数，σⱼ = cⱼ − zⱼ。max 问题里 σⱼ > 0 表示增加 xⱼ 还能让目标函数变好；全部 σⱼ ≤ 0 就达到最优了。
  • 基变量当前基对应的变量，就是表格左边「基」那一列；退化时基变量也可以取 0，其余非基变量取 0。
  • z目标函数的值。

指派问题

匈牙利法 · 逐步迭代

行 = 人员（也可以是机器、车辆…），列 = 工作（也可以是任务、地点…）。 单元格里填数字（费用或收益），填 × 表示这个人不能做这件事；空格按 0 计。 「− 行 / − 列」删掉的是最后一行 / 最后一列。人数与工作数不一样也能算，程序会自动补虚拟行列。
